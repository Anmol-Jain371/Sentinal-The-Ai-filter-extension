// SYSTEM SPECIFICATION & ARCHITECTURE

Client-Side Browser Security & Contextual DLP

SentinelX is a privacy-first Chromium browser security runtime (Manifest V3) engineered to intercept and prevent accidental or malicious exposure of proprietary credentials, source code, and PII to external AI tools and unapproved SaaS destinations.

Exposure Risk Score (0-100) = f(Data Sensitivity, Destination Trust, Volume, Action, Context)

Core Architectural Pillars

01
Shannon Entropy Analysis
Calculates localized information entropy H(X) ≥ 4.2 bits/char to catch zero-day API keys and passwords without static regex prefixes.
02
Closed Shadow DOM HUD
All in-page dialogs mount inside attachShadow({mode: 'closed'}) preventing host page scripts from reading or manipulating security actions.
03
Semantic Smart Masking
Replaces secrets with structured semantic tokens [STRIPE_SECRET_1] so developer prompts remain functional while credentials stay protected.
04
Zero-Knowledge Telemetry
Plaintext never leaves the browser. SOC ingestion receives strictly anonymized SHA-256 event fingerprints and metadata.
05
Sub-5ms Execution
Synchronous DOM paste interception evaluates heuristics and policy boundaries with zero perceived keystroke lag.
